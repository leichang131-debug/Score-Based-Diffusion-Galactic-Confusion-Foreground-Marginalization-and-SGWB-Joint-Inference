# TaijiSGWB official inputs

The official TDC II 2.8 training set is downloaded to ignored `data/raw/taiji-sgwb/TDCII2.8.h5`. Its published orbit is at ignored `data/raw/taiji-sgwb/MicroSateOrbitEclipticTCB/MicroSateOrbit.hdf5`. Original official filenames are retained.

[Download/check commands and verified structure](../../docs/reproduction/taiji-sgwb/data-preparation.md). [Checksums and evidence](../../results/taiji-sgwb/data/README.md).

The original demo's hyphenated filename is supplied by a runtime symlink, not by renaming the official file. Only the 2.8 realistic-orbit training set is prepared at this stage. Raw data and runtime files are intentionally outside normal Git history.
