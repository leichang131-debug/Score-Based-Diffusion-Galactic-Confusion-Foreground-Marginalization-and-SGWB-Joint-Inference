# Route A and Route B implementation plan

The v1.1 plan defines the ten-parameter study based on Liang et al.'s full-covariance Taiji framework. It specifies the shared physical model and validation, Route A Gaussian inference, Route B score-based likelihood correction and sampling, and the evidence and figure requirements for paired comparisons.

- [Implementation and acceptance plan (PDF)](route-ab-implementation-plan-v1.1.pdf)
- [Editable LaTeX source](route-ab-implementation-plan-v1.1.tex)

The plan is written in Chinese. Route A and Route B are planned experiments. The implementation and evidence status is tracked in the [research results index](../../../results/research/README.md).
