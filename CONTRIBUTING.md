# Contributing

Use English for new code, documentation, configuration keys, commit messages, and issue descriptions. Preserve the archived research plan in its original language.

Create focused branches and explain the scientific question and resulting behavior in each change. Separate upstream source changes from project adapters. Record and review dependency and source versions.

A reproduction report must state what actually ran, the exact commands and configuration, hardware, elapsed time, source commits, dependency lock, data provenance, and artifacts. Report incomplete convergence and failed checks explicitly.

Validation must match the scientific claim. Generated samples and a decreasing training loss alone do not demonstrate calibrated inference. Use independent realizations and prevent training/test leakage.

Preserve third-party notices and licenses. Use small curated artifacts in Git and an artifact manifest for large datasets, weights, and posterior chains.
