# SGWB research modules

[Physics](physics/README.md) and [data](data/README.md) serve both routes. [Likelihoods](likelihoods/README.md) covers the Gaussian baseline and probability-flow density. [Models](models/README.md) covers conditional residual score training. [Inference](inference/README.md) covers posterior sampling and recovery. [Validation](validation/README.md) covers numerical checks and paired scientific evaluation.

The module directories document planned responsibilities. Executable route-specific commands will be indexed under [research scripts](../../scripts/research/README.md).
