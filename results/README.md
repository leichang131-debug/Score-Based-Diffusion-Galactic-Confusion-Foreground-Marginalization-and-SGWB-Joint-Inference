# Research results

Track curated figures, tables, summaries, and artifact manifests here. Each result must point to its configuration, source version, environment, seed, data provenance, and validation status. No experiment result is included at initialization.

Large checkpoints, data, and posterior chains should have durable storage locations and checksums in manifests. Use laboratory storage, Git LFS, or releases as appropriate; do not silently omit the record of a result.
