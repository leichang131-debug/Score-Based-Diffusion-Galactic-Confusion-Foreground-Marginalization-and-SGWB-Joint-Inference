## Completed schedule versus statistical validation

The run completed 1000 burn transitions plus 350 saved production ensembles with `thin_by=12`, totaling 5200 transitions. Cold output shape is 350 x 62 x 14. The 21700 draws are correlated, not independent samples. Only 2/14 predeclared conservative parameter diagnostic flags pass. There are no independent seeded ensembles or repeated-injection calibration. The correct status remains `SAMPLING_COMPLETE_CONVERGENCE_NOT_CONFIRMED`.

The SGWB sampled medians and 16–84% intervals remain Omega0 = 9.5567e-13 [8.7695e-13, 1.03885e-12], alpha = 0.68020 [0.63466, 0.72659]. The injections lie in these intervals; that fact alone is not a convergence or coverage test.
